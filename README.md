# MuseumNightGame
A trivia-game designed to be used for museum night at Córdoba, Argentina. 

# Disclaimer
This is a functional game but it is not the final version of it. Once it is finished, this README will be aswell.

# Dependencies
You need customTkinter in order to be able to execute the program.
Be sure to execute it (by python3 intento1.py) from /linux_gam
